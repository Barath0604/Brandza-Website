# Brandza website

A responsive, multi-page static website ready to host on any web server or static hosting service. It uses plain HTML, CSS, and JavaScript; no build step or package installation is required.

## Preview locally

Open `index.html` in a browser. The site has separate Home, Services, Projects, About, and Contact pages. For hosting, upload every `.html` file, `styles.css`, `script.js`, and `brandza-logo.png` together, preserving the filenames.

## Before publishing

1. Replace the illustrative stock photos with Brandza's own project photography. Every portfolio photo is labeled **Concept visual** and the portfolio has an explanatory note so it is not presented as completed client work.
2. Replace `hello@brandza.in` in `index.html` and `contact.html` with the business's real email address. Contact actions open the visitor's email app; no backend is needed.
3. Add the operating city, phone/WhatsApp number, social links, and verified client testimonials if desired.
4. Review the service descriptions and remove anything that does not match the actual services offered.
5. The logo image was supplied with a black background. It is displayed on dark backgrounds to preserve its appearance.

The page loads fonts and portfolio imagery from Google Fonts and Unsplash. Those assets require an internet connection. For fully self-contained hosting, download licensed image and font assets and update their references.
